# Modulife Store
A responsive premium e-commerce front-end for MODULIFE STORE.

Included:
- Homepage with hero, categories, trust bar, deals, collections, reviews and newsletter
- Shop with category/price/rating filters and sorting
- 25 sample products
- Cart with localStorage
- Checkout modal with Cash on Delivery
- Direct WhatsApp checkout: +92 304 4637523
- Customer name, phone, email, city, province, complete address, postal code, notes and full product/cart details are included in the WhatsApp message
- No EmailJS, backend or database required
- Responsive mobile navigation and bottom-friendly layout
- Product quick view, wishlist placeholder, search
- Supplied Facebook logo crop used as brand logo

This is a front-end demo. Orders are sent directly to WhatsApp using a pre-filled wa.me message. The site does not store orders in a database or require a backend.
